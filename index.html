How to Password Protect an Excel File — Opening and Editing

Whether you need to lock down financial reports, hide specific cells, or secure a workbook for email distribution, applying the right password protection prevents unauthorized access. This guide breaks down the difference between open passwords, permissions, and professional file encryption.

Editorial Team · Updated May 2026 · 8 min read
Quick Answer

To password protect an Excel file from opening: Open your workbook in Excel. Go to File > Info > Protect Workbook > Encrypt with Password. Type a strong password, click OK, confirm it, and save the file. Anyone attempting to open this file will now be required to enter the password before viewing any data.

Topic Overview

What Happens When You Password Protect an Excel File

Adding a password to your Excel file does two things depending on how you configure it. An open password uses Excel's built-in AES-256 encryption to scramble the file's contents, making it unreadable without the exact key. A permissions password (or edit password) allows anyone to open the file, but restricts changes, preventing users from altering formulas or editing specific sheets.

How to Password Protect Excel File from Opening

Many users specifically search for how to completely block access to a file. The native "Encrypt with Password" feature is the Microsoft standard for this. When applied, the file cannot be previewed in Windows Explorer, read by macro scripts, or imported into Google Sheets without the password.

Built-In Solutions

How to Password Protect an Excel File — Complete Guide

Method 1: Encrypt with Password (Full File Lock)

This is the native method requiring Microsoft Excel. It locks the entire file.

  1. Click File in the top ribbon.
  2. Navigate to Info.
  3. Click the Protect Workbook dropdown.
  4. Select Encrypt with Password.
  5. Enter your password and verify it. Save the document.

Limitations: This must be done manually for every single file. It does not prevent someone from deleting the file entirely from your hard drive or moving it to an external USB stick.

Security Level

Moderate

Excel's AES-256 is mathematically secure, but local files remain vulnerable to deletion and USB transfer.

Method 2: Password Protect an Excel Workbook vs Sheet

If you want users to view the data but not break your formulas, you need structural protection.

  • Protect Sheet: Prevents users from editing specific cells or formatting. (Review > Protect Sheet).
  • Protect Workbook: Prevents users from adding, deleting, or hiding entire tabs/sheets. (Review > Protect Workbook).

Common Mistake: Relying on Sheet Protection for security. Sheet passwords are not encrypted and can be easily bypassed by changing the file extension to .zip and editing the internal XML. Never use Sheet Protection for sensitive data.

Best Used For

Office collaboration, preventing accidental formula overwrites, and read-only distribution.

Technical Details

Advanced Security & Encryption Standards

Modern Excel files (2013 and newer, saving as .xlsx) utilize AES-256 bit encryption. This is military-grade standard. If you use a strong, unique password, it is computationally impossible to brute-force the encryption within a human lifetime. However, older .xls files (Excel 2003 and earlier) used weak RC4 algorithms that can be cracked in seconds.

What to Do If You Forget a Document Password

If you are the legitimate owner of an Excel file and have forgotten your password, your recovery options are strictly limited by design. AES-256 encryption is specifically built to have no "backdoors".

Common Questions

Frequently Asked Questions

How to password protect an Excel file from being opened?

Open the file, click File > Info > Protect Workbook > Encrypt with Password. Enter your password, confirm it, and save the file. The next time it is opened, Excel will prompt for the password.

How to remove password protection from Excel?

You must know the current password to remove it. Open the file and enter the password. Go to File > Info > Protect Workbook > Encrypt with Password. Delete the dots in the password field so it is completely blank, click OK, and save the file.

Can Google open a password-protected Office file?

No. Google Drive and Google Sheets cannot decrypt AES-protected Excel files. You must remove the password using Microsoft Excel before you can import or edit the file in Google Workspace.

Can I batch password protect multiple documents?

Native Excel does not support batch protection. To protect multiple files at once, you must place them in an encrypted ZIP file (using tools like 7-Zip) or use dedicated vault software like Folder Lock.

Our Verdict

For sharing a single spreadsheet via email, Excel's native "Encrypt with Password" feature is the right choice. It is free, built-in, and uses strong AES-256 encryption. However, for local file security—where you need to prevent files from being seen, copied, or deleted from your own PC or USB drive—native Office features are insufficient.
